# 🛒 Supermarket Sales Analysis

## 📌 Project Overview

This project analyzes supermarket sales data using Python, Pandas, Matplotlib, SQL, and Streamlit. The objective is to identify sales trends, customer behavior, and profitable product categories through data analysis and visualization.

## 🎯 Objectives

- Analyze sales performance
- Identify the highest-performing branch
- Find the most profitable product line
- Analyze payment methods
- Study monthly sales trends
- Build an interactive Streamlit dashboard

## 🛠️ Tools Used

- Python
- Pandas
- NumPy
- Matplotlib
- SQL
- Streamlit

## 📂 Project Structure

- `data/` – Dataset
- `notebooks/` – Google Colab notebook
- `sql/` – SQL queries
- `streamlit/` – Streamlit dashboard
- `charts/` – Visualization images
- `report/` – Final project report

## 📊 Visualizations

- Sales by Branch
- Payment Methods
- Monthly Sales Trend
- Customer Ratings Distribution
- Product Line Profit

## 📈 Dashboard Features

- Total Revenue
- Total Customers
- Best Branch
- Best Product Line
- Highest Revenue Month
